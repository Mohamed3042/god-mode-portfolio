# God Mode Portfolio 2.0.0

## Calm interface

- The hub now answers “Which world?” first, with seven compact identity choices before supporting proof.
- Every identity page keeps its own palette, typography, voice, and original MOHAMED wordmark while using a calmer reading hierarchy.
- The fixed navigation now shows previous, current, and next context, with all eight routes available from one accessible Worlds disclosure.
- A persistent 36 px orientation strip states where the visitor is, the page question, and the next useful destination.
- Load gates, shared reveal choreography, count-up animation, and the custom trailing cursor were removed. Reduced-motion visitors receive the same complete, formatted content immediately.
- Base typography, reading measure, focus treatment, spacing, and interaction timing were normalized without changing profile facts or project metrics.

## Public metadata and proof

- Canonical, Open Graph, sitemap, and robots URLs now point to `https://mohamed3042.github.io/god-mode-portfolio/`.
- The visible footer is sourced from the package manifest and reports `v2.0.0`.
- `scripts/verify-calm.mjs` checks all eight routes at phone and desktop sizes, reduced motion, navigation and block limits, link fragments, metadata, sitemap/robots, overflow, and visible version.
- Lighthouse is pinned as a development-only audit dependency for reproducible mobile performance and accessibility reports.

No profile facts, metrics, tribute boundaries, runtime framework, or GitHub Pages deployment workflow changed.
